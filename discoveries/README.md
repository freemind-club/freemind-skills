# Находки

В отличие от `skills-base/` (наши собственные скиллы, готовые к установке), здесь — интересные внешние репозитории и инструменты, которые мы изучили и оценили. Не всё отсюда стоит устанавливать — у каждой записи есть вердикт: полезно / кандидат на будущее / не подошло, и почему.

| Категория | Что внутри |
|-----------|-----------|
| [hermes-ecosystem/](hermes-ecosystem/) | Скиллы для Hermes-agent — отдельная экосистема, которую мы реально используем (kanban) |
| [agent-tooling/](agent-tooling/) | Мета-инструменты для агентов: генераторы CLI, загрузчики и т.д. |
