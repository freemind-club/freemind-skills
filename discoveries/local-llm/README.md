# Локальные и бесплатные LLM

Инструменты для запуска LLM локально или бесплатного доступа к облачным моделям.

| Находка | Что делает | Хештеги |
|---------|-----------|---------|
| [freellmapi](https://github.com/tashfeenahmed/freellmapi) | Единый OpenAI-совместимый endpoint для 16+ бесплатных LLM-тиров (Google, Groq, Cerebras, NVIDIA и др.) — авто-роутинг под запрос, автопереключение при rate limit, ~1.7B токенов/мес суммарно, ключи в зашифрованном виде. 15.9K ⭐ | `#llm` `#free` `#router` `#failover` |
| [AnythingLLM](https://github.com/Mintplex-Labs/anything-llm) | All-in-one workspace для чата с документами и создания агентов | `#localllm` `#rag` |
| [KoboldCpp](https://github.com/LostRuins/koboldcpp) | Лёгкий инструмент, хорош для creative writing и сценариев с персонажами | `#localllm` `#creative` |
| [llama.cpp](https://github.com/ggml-org/llama.cpp) | Базовый движок — очень эффективный, запускается почти на любом железе | `#localllm` `#engine` |
| [Open WebUI](https://github.com/open-webui/open-webui) | Веб-интерфейс в стиле ChatGPT, отлично работает с Ollama | `#localllm` `#ui` |
| [GPT4All](https://github.com/nomic-ai/gpt4all) | Простое desktop-приложение со встроенным чатом по документам | `#localllm` `#desktop` |
| [LocalAI](https://github.com/mudler/LocalAI) | OpenAI-совместимый API на разном железе, много backend'ов | `#localllm` `#api` |
| [vLLM](https://github.com/vllm-project/vllm) | Быстрый inference engine для более быстрых ответов и работы в масштабе | `#localllm` `#inference` `#scale` |
