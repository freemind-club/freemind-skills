# Нишевые находки

Инструменты вне основного фокуса FreeMind (маркетинг, боты, контент, автоматизация бизнеса) — записаны на случай, если пригодятся для специфичных задач студентов клуба (безопасность, расследования, мобильная разработка). Мы их не используем и не тестировали.

| Находка | Что делает | Хештеги |
|---------|-----------|---------|
| [OpenPlanter](https://github.com/ShinMegamiBoson/OpenPlanter) | Опенсорсный аналог Palantir — ИИ-агент для расследований: объединяет данные из разных источников, находит связи людей/компаний/контрактов, строит граф связей с указанием источника. Работает с OpenAI, Anthropic, локальными моделями через Ollama | `#osint` `#investigation` `#niche` |
| [SearchPhone](https://github.com/HackUnderway/SearchPhone) | Анализ телефонных номеров: оператор и геоданные (Numverify), упоминания в Google/Bing/DuckDuckGo, поиск в GitHub-коде и на Reddit, JSON/PDF-отчёты. Позиционируется как инструмент для легальных проверок и threat intelligence | `#osint` `#phone` `#niche` |
| [RepoStore](https://github.com/samyak2403/RepoStore) | Поиск Android-приложений (APK) среди GitHub-репозиториев с описанием и рейтингом, разбивка по категориям | `#android` `#apk` `#niche` — ⚠️ по сути каталог APK из открытых репо, юридический статус конкретных приложений не проверяли |
