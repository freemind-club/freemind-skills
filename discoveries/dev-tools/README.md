# Dev-инструменты

Бесплатные/free-tier инструменты для разработки — не скиллы, а сервисы и библиотеки.

| Находка | Что делает | Хештеги |
|---------|-----------|---------|
| [Aider](https://github.com/Aider-AI/aider) | AI pair programming прямо в терминале | `#coding` `#terminal` |
| [Sourcegraph](https://sourcegraph.com) | Поиск по репозиториям и большим кодовым базам | `#search` `#codebase` |
| [Browserbase](https://browserbase.com) | Облачные браузеры для автоматизации, тестов и AI-агентов | `#browser` `#automation` `#cloud` |
| [Resend](https://resend.com) | Email API для транзакционных писем и React-шаблонов | `#email` `#api` |
| [Sentry](https://sentry.io) | Ошибки, crash reporting, performance monitoring | `#monitoring` `#errors` |
| [Public APIs](https://github.com/public-apis/public-apis) | Большой список бесплатных публичных API для проектов и прототипов | `#apis` `#free` `#list` |
| [GStack](https://github.com/garrytan/gstack) | Сетап Garry Tan для Claude Code — 23 opinionated tools | `#claudecode` `#setup` |
| [GitHub Pages](https://pages.github.com) | Бесплатный хостинг статических сайтов из GitHub-репозитория | `#hosting` `#static` `#free` |
| [Mellea](https://github.com/generative-computing/mellea) | Python-библиотека для предсказуемых LLM-приложений — типизированные generative-программы: Pydantic-схемы вместо свободного текста, авто-repair, rejection sampling, majority voting. От IBM Research, Apache 2.0 | `#python` `#llm` `#pydantic` `#structured-output` |
| [Meetily](https://github.com/Zackriya-Solutions/meetily) | Бесплатный локальный ИИ-секретарь для созвонов: расшифровка в реальном времени, разделение спикеров, саммари локальной нейронкой, без облака. macOS/Windows/Linux, поддержка русского, подключается к Claude/Codex | `#meetings` `#transcription` `#local` |
