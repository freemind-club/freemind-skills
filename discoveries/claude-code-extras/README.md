# Claude Code extras

Скиллы и подходы, расширяющие Claude Code за рамки built-in возможностей.

| Находка | Что делает | Хештеги |
|---------|-----------|---------|
| [Hyper Research](https://github.com/jordan-gibbs/hyperresearch) | Скилл для Claude Code: 16-этапный research-агент — матрица покрытия темы, поиск противоречий между источниками, contrarian-проверка своих же выводов, черновик → редактура → полный отчёт с базой источников | `#research` `#claudecode` `#skill` |
| [OpenWiki](https://www.npmjs.com/package/openwiki) | CLI от LangChain: генерирует и обновляет wiki репозитория (архитектура, CLI, операции) в отдельную папку, а в CLAUDE.md/AGENTS.md оставляет короткую ссылку — не даёт агентным инструкциям раздуваться | `#docs` `#claudecode` `#agents` |
| [awesome-codex-subagents](https://github.com/VoltAgent/awesome-codex-subagents) | 130 сабагентов для Codex CLI — код, тексты, картинки/видео, аналитика, Go/Rust, Kubernetes/Terraform. Тяжёлые задачи на GPT-5.4, лёгкие на GPT-5.3, каждый в изолированном контексте | `#codex` `#subagents` |
| Claude Cowork — "Record a skill" | Функция Claude Cowork: включаешь запись экрана, выполняешь задачу с озвучкой — Claude превращает это в скилл, который повторяет сам | `#claude` `#news` `#skillcreation` |
