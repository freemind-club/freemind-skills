# Режим pro — разбор клиента перед созвоном

Когда: есть выгрузки, отчёты, несколько месяцев цифр, или Олег просит «режим pro».

1. **Данные.** Свести в две карточки: текущий период и такой же прошлый (месяц к месяцу прошлого года — для сезонных). `calc.py --card now.csv --prev before.csv`. Для сети точек — по каждой точке отдельно + сеть.
2. **Стоп-проверки — все 16** (`04_freemind/03_Продукт/метод_горлышко/СТОП-ПРОВЕРКИ_горлышки.md`), каждая ✅/🟡/⛔ с фактом.
3. **ГДЕ** — `dynamics`: что просело сильнее всего. Отделить симптом (план не выполнен, выручка упала) от множителя (число чеков упало, чек вырос).
4. **ЧТО** — кандидаты Голдратта: поток покупателей, обработка заявок, планирование, люди, учёт, сбои. Выбрать одно.
5. **ПОЧЕМУ** — цепочка по фактам из данных, каждое звено со ссылкой на цифру; «следовательно».
6. **Развилка** — процесс / человек / смешанный, как в студенческом режиме.
7. **На созвон** — 5–7 вопросов, которые подтвердят или опровергнут диагноз (что может сделать падение «бумажным»: ушли ли продажи на другие кассы, закрытия, сбои).
8. **Отчёт** — шаблон студента + раздел «Вопросы на созвон» + `mode: pro` в блоке yaml.

Полные промпты по шагам — `04_freemind/03_Продукт/метод_горлышко/ПРОМПТЫ_ДИАГНОСТИКИ.md`.
Данные клиента — только в его папке `ДАННЫЕ/`, не в git и не в общую память.
