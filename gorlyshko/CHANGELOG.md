## 0.4.0 — 2026-11-21

## 0.3.0 — 2026-11-20
- Упаковка: `install.sh` (Claude Code + Hermes, закреплённый тег, резервная копия в ~/.gorlyshko-backup вне папки скиллов, без sudo, версия валидируется regex), `README.md` (для человека + «Для ИИ-агента»), `PROMPT.md` (промпт для любой нейросети без установки). Скилл первым делом просит CSV карточки.
- Безопасность (чек-лист раздаваемых скиллов): нет eval; ввод версии — regex; секретов нет; sudo/curl|sh не автоматом (скачать → прочитать → запустить); тег пиннут; без python скилл деградирует (предупреждает); данные пользователя никуда не отправляются. Smoke-test установщика офлайн в изолированном HOME — пройден.

## 0.2.2 — 2026-11-20
