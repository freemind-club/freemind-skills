# Автозагрузка `my-director` при старте сессии

Цель: чтобы `my-director` подхватывался каждую сессию без ручного `/my-director`.

## Вариант 1 — SessionStart хук (рекомендуется)

Добавить в `~/.claude/settings.json` (создать, если нет). Если ключ `hooks` уже есть — влить, не затирать.

```json
{
  "hooks": {
    "SessionStart": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "echo 'Загрузи скилл my-director и следуй протоколу СТАРТ.'"
          }
        ]
      }
    ]
  }
}
```

Хук печатает напоминание в контекст сессии — ассистент видит его и грузит скилл сам.

**Мастер добавляет хук только если:**
- `~/.claude/settings.json` — валидный JSON (или отсутствует)
- в `SessionStart` ещё нет такого же напоминания

Иначе — показать пользователю блок и попросить вставить руками.

## Вариант 2 — строка в корневом `CLAUDE.md` проекта

Если у пользователя есть `{{PROJECT_PATH}}/CLAUDE.md` — добавить наверх:

```markdown
## При старте
Загрузить скилл `my-director` и выполнить протокол СТАРТ.
```

## Вариант 3 — вручную

Пользователь сам пишет `/my-director` в начале каждой сессии. Ничего не трогаем.

## Проверка

После настройки — сказать пользователю: «Открой новую сессию, ассистент должен сам начать с брифинга. Если нет — напиши `/my-director`.»
