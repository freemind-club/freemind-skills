# Eval: активация скилла `director`

Скилл — мастер настройки. Грузится, когда пользователь хочет **поставить / перенастроить директора**. Не грузится на обычных задачах.

## ДОЛЖЕН загрузиться

| Фраза | Почему |
|-------|--------|
| «настрой директора» | прямой триггер |
| «/director» | команда |
| «собери мне AI-директора» | синоним |
| «хочу поставить директора из клуба FreeMind» | продукт по имени |
| «set up my director» | англ. триггер |
| «перенастрой директора, поменялась модель» | Режим B |
| «поставь директора в Hermes» | среда + продукт |
| «у меня есть промокод FreeMind, что дальше» | контекст активации |

## НЕ должен загружаться

| Фраза | Почему нет |
|-------|-----------|
| «напиши пост для канала» | контент, не настройка |
| «сколько подписчиков в марте» | запрос к памяти |
| «задиректорь эту задачу субагенту» | обычная работа директора, не установка |
| «почини вебхук n8n» | n8n-задача |
| «что такое память директора» | вопрос, не действие (граница — если «объясни» → нет; если «настрой» → да) |
| «сделай ревью кода» | не про директора |

## Что делать при провале

- Ложное срабатывание → в `description` убрать широкие слова, оставить «настрой/собери/поставь директора», «/director», «set up director».
- Не сработал на нужном → добавить недостающий синоним в триггеры `description`.
- `description` не должно быть длиннее ~1-2 предложений сути + список триггер-фраз.
