# Evals — Директор

Три проверки: **активация** (грузится ли скилл когда надо), **сборка** (валиден ли результат визарда), **золотой прогон** (эталон для сравнения).

Запуск — вручную ассистентом (автоматики нет). Прогонять: перед публикацией новой версии и после правок `SKILL.md` / `core/*`.

| Файл | Что проверяет |
|------|---------------|
| [activation.md](activation.md) | триггеринг `description` — грузится на нужных фразах, не грузится на лишних |
| [build-checklist.md](build-checklist.md) | сгенерированный `my-director` валиден и не сломал данные пользователя |
| [golden-run.md](golden-run.md) | эталонные прогоны (full / lite) — с чем сравнивать реальный |

## Как прогнать активацию

Для каждой фразы из `activation.md` спросить: «загрузился бы скилл `director` по этому сообщению?» — да/нет. Сверить с ожидаемым. Расхождение → править `description` в `SKILL.md` (короче, конкретнее триггеры).

## Как прогнать сборку

После реального `/director` — пройти `build-checklist.md` по сгенерированному `my-director`. Любой ❌ → сборка не считается завершённой.

## Как использовать золотой прогон

`golden-run.md` описывает входы интервью и ожидаемую структуру на выходе для двух тиров. Реальный прогон должен давать ту же структуру файлов, те же подставленные значения в тех же местах, ноль `{{...}}`.
