# Память — `native` / `files` (штатная / файловая)

> Рабочий, полноценный вариант памяти — не «урезанный». `native` = штатная память среды (Hermes/Cursor). `files` = локальные `MEMORY.md` + `journal.md`.
> Апгрейд до смысловой памяти (`lightrag` / `lightrag_postgres`) — когда появится потребность в графе связей и аналитике. Клуб FreeMind: {{CLUB_LINK}}

## Хранилище

`~/.claude/skills/my-director/memory/`
- одна мысль — один файл `<slug>.md` с frontmatter (`name`, `description`, `type: decision|fact|preference|bug|personal`)
- `memory/MEMORY.md` — индекс, одна строка на файл: `- [Заголовок](file.md) — крючок`

## Что писать

1. Решения (что решили и почему)
2. Факты о проектах, не выводимые из кода/гита
3. Предпочтения {{USER_NAME}}
4. Баги и решения
5. Личное/контекст

Формат: 1–3 предложения, проект + причина.

## Что НЕ писать

Код, логи, дампы, черновики, то что уже в репозитории.

## Старт сессии

Прочитать `MEMORY.md`, открыть нужные файлы по теме.

## Правила

- Перед записью — проверить, нет ли уже файла на эту тему; обновлять, не плодить дубли
- После записи — показать содержимое файла, не «готово»
- Команды: «запомни X» → создать/обновить файл + строку в MEMORY.md; «вспомни X» → найти и показать
