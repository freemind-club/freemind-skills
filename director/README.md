# Директор — мега-скилл клуба FreeMind

Превращает AI-ассистента из «исполнителя» в **директора**: он делегирует вместо ручного труда, помнит контекст между сессиями, ведёт протоколы, соблюдает жёсткие правила безопасности и учится на своих косяках.

Это **мастер**: под интервью собирает *твоего* директора — под твою среду, твои проекты, твои модели, твои правила.

---

## Среды

| Среда | Формат директора |
|-------|------------------|
| Claude Code (CLI + Desktop) | скилл `~/.claude/skills/my-director/` |
| Hermes | блок в `~/.hermes/SOUL.md` |
| Cursor / Cline / Windsurf | блок в файле правил |
| OpenAI Codex CLI | блок в `AGENTS.md` |
| Qwen Code CLI | блок в `QWEN.md` |
| n8n (AI Agent нода) | текст в System Message |
| любой другой агент | один блок в system-prompt |

Мастер сам определяет среду и подтверждает. Можно поставить в несколько сред. На `native`/`files` память у каждой среды своя. Общей она станет только после отдельного осознанного подключения общего хранилища (граф-память).

---

## Установка

> **Ядро (доктрина) — стабильно.** Установщик и адаптеры сред — **beta**: ставь одну среду за раз, после установки проверь, что директор подхватился. Установщик под несколько сред и авто-определение среды ещё дорабатываются.

Нужен промокод клуба.

```bash
curl -fsSL https://raw.githubusercontent.com/freemind-club/freemind-skills/main/director/install.sh | bash
```

Или безопаснее: скачай `install.sh` из репо, посмотри код, запусти локально.

Спросит промокод → положит мастер-скилл в каталог скиллов найденной среды (`~/.claude/skills/director`, `~/.hermes/skills/director` и т.п.). Если сред несколько — спросит куда; если ни одной не нашёл — честно об этом скажет и остановится.

Вручную: скопировать папку `director/` в каталог скиллов своей среды.

Дальше — в Claude Code (или другом агенте, где ведёшь настройку):

```
/director
```

## Что спросит мастер

**Базовый слой:**
- как обращаться, ниша, язык, где проекты + git
- **память:** долговременная память между сессиями обязательна **как функция** — без неё директор каждый раз начинает с нуля. Бэкенд — по среде:
  - `native` — штатная память среды (Hermes, Cursor). Ставится сразу, 0 зависимостей.
  - `files` — `MEMORY.md` + `journal.md` в каталоге директора (Claude Code, generic). 0 зависимостей, 2 минуты.
  - Ни Docker, ни внешние сервисы не нужны.
- модель-оркестратор (сам директор) и исполнители для дешёвой пачки (субагенты / свой endpoint / Ollama / Groq / …)
- инструменты под управлением, тест-среда, что = прод, куда слать алерты
- участник клуба со стеком FreeMind? → подключит модуль

**Точечный слой (по желанию):** автономия, уточнение моделей, часы тишины, стиль коммитов, verbosity, ты/вы, свои жёсткие правила. Плюс скан скиллов среды.

## Память: `files`/`native` и когда нужно больше

`files` и `native` — рабочие варианты, директор на них полноценно функционирует. Потолок наступает на большом объёме: recall = «прочитать индекс, открыть файлы по теме», нет семантического поиска и связей между фактами, цифры (клиенты, метрики) живут только в тексте. **Без граф-памяти директор помнит хуже: чаще переспрашивает и тратит больше токенов на повторный разбор того, что уже знал.**

Снимает это **граф-память** (LightRAG + опционально PostgreSQL) — но она требует Docker, сервер и сопровождение, поэтому **не входит в пакет и директор её не ставит**. Это необязательный ручной апгрейд, решение за тобой.

Ставится отдельно — модуль `mozg` репозитория `freemind-setup` (`github.com/freemind-club/freemind-setup`): скачай `install.sh`, проверь код и SHA-256, запусти локально.

Порядок: запусти директора на `native`/`files` → поработай → упрёшься в потолок → сам решишь, ставить ли граф-память → потом в `/director` сменишь бэкенд и перенесёшь заметки. Помощь и контекст — клуб FreeMind.

## Уровни доступа

Промокод определяет уровень. Код даётся в клубе / на интенсиве — [как получить](#нет-промокода).

| Уровень | Что даёт |
|---------|----------|
| **полный** | всё: точечная настройка, любые модели и шлюзы, FreeMind-модуль, авто-самоулучшение (директор сам дописывает `journal.md` и правила) |
| **lite** | ядро директора целиком (делегирование, протоколы, железные правила), делегирование только субагентами. Нет: точечной настройки, FreeMind-модуля, авто-самоулучшения (журнал ведётся вручную) |

Память (`native`/`files`) в обоих уровнях одинаковая — это не признак lite.

## Что создаётся (пример для Claude Code)

```
~/.claude/skills/my-director/
├── SKILL.md          # рантайм — грузится каждую сессию
├── profile.md        # твои ответы
├── journal.md        # журнал косяков и успехов (ведёт сам)
├── memory/           # бэкенд files: заметки + MEMORY.md индекс
└── references/        # core/00–06 + skills.md + models.md
```

Мастер предложит автозагрузку (SessionStart-хук для Claude Code; для остальных сред файл правил читается сам).

## Переконфигурация

```
/director
```

Профиль есть → спросит, что менять. `journal.md`, `MEMORY.md` / штатная память и данные в граф-памяти (если подключена) не трогаются.

## Ничего не сломает

Перед любыми изменениями визард делает **снимок** (`~/.director-backup/<дата>/`): копии конфигов, инструкций твоего агента, дампы БД клиента (если директор получит к ней write-доступ) + скрипт отката `restore.sh`.

- Сначала показывает, что у тебя уже есть, и что предлагает подключить — **ничего не удаляя**.
- Существующую базу / MCP / уже развёрнутую граф-память — подключает, не пересоздаёт.
- Если сборка не удалась: `restore.sh` из снимка возвращает на место **конфиги и файлы инструкций агента** и сносит полусобранного директора, затем визард сверяет восстановленное с `MANIFEST.md` (sha256 файлов, список MCP). **БД клиента (если её трогали) `restore.sh` не восстанавливает** — это делается отдельно вручную из дампа в снимке. Возврата всего состояния одной кнопкой визард не обещает.
- Откат вручную в любой момент: `bash ~/.director-backup/<дата>/restore.sh` (конфиги и файлы; БД — из дампа рядом).

## Приватность

Фаза 1: промокод проверяется локально, ничего не отправляется. Секреты (ключи, токены, строки подключения) в файлы скилла открытым текстом не пишутся — только ссылки на твои локальные файлы.

## Требования

- один из поддерживаемых агентов (см. «Среды»)
- git
- для делегирования на свой endpoint — рабочий OpenAI-совместимый API

Docker и внешние сервисы **не требуются** — память работает на `native`/`files`.
