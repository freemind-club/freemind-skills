# Директор — мега-скилл клуба FreeMind

Превращает AI-ассистента из «исполнителя» в **директора**: он делегирует вместо ручного труда, помнит контекст между сессиями (два полушария памяти), ведёт протоколы, соблюдает жёсткие правила безопасности и учится на своих косяках.

Это **мастер**: под интервью собирает *твоего* директора — под твою среду, твои проекты, твои модели, твои правила.

---

## Среды

| Среда | Формат директора |
|-------|------------------|
| Claude Code (CLI + Desktop) | скилл `~/.claude/skills/my-director/` |
| Hermes | блок в `~/.hermes/SOUL.md` + MCP |
| OpenClaw | блоки в `AGENTS.md` + `USER.md` |
| Cursor / Cline / Windsurf | блок в файле правил + MCP |
| OpenAI Codex CLI | блок в `AGENTS.md` + MCP |
| Qwen Code CLI | блок в `QWEN.md` + MCP |
| n8n (AI Agent нода) | текст в System Message + MCP-нода |
| любой другой агент | один блок в system-prompt |

Мастер сам определяет среду и подтверждает. Можно поставить в несколько — память общая.

---

## Установка

Нужен промокод клуба.

```bash
curl -fsSL https://raw.githubusercontent.com/freemind-club/freemind-skills/main/install.sh | bash -s director
```

Проверит промокод → положит мастер-скилл в `~/.claude/skills/director`.

Вручную: скопировать папку `skills/director/` в `~/.claude/skills/director/`.

Дальше — в Claude Code (или другом агенте, где ведёшь настройку):

```
/director
```

## Что спросит мастер

**Базовый слой:**
- как обращаться, ниша, язык, где проекты + git
- **память — два полушария:** LightRAG (смыслы, решения, контекст) + PostgreSQL (факты, цифры, клиенты). Обязательна. Мастер поможет развернуть вложенным скиллом — локально или на сервере. (в lite — файловая)
- модель-оркестратор (сам директор) и исполнители для дешёвой пачки (субагенты / свой endpoint / Ollama / Groq / …)
- инструменты под управлением, тест-среда, что = прод, куда слать алерты
- участник клуба со стеком FreeMind? → подключит модуль

**Точечный слой (по желанию):** автономия, уточнение моделей, часы тишины, стиль коммитов, verbosity, ты/вы, свои жёсткие правила. Плюс скан скиллов среды.

## Быстрый старт (без Docker)

Не хочешь возиться с LightRAG/Postgres сейчас — стартуй на файловой памяти:
`/director` → выбери «файловая память сейчас, апгрейд позже». Получишь рабочего директора за 5 минут (ядро + один адаптер + `memory/`). Апгрейд до двух полушарий — потом, через `/director` (данные перенесутся).

## Уровни доступа

Промокод определяет уровень. Код даётся в клубе / на интенсиве — [как получить](#нет-промокода).

| Уровень | Что даёт |
|---------|----------|
| **полный** | всё: точечная настройка, апгрейд памяти до двух полушарий, любые модели, FreeMind-модуль, авто-самоулучшение |
| **lite** | ядро директора целиком, но память только файловая, делегирование только субагенты, без точечной настройки и FreeMind-модуля |

## Что создаётся (пример для Claude Code)

```
~/.claude/skills/my-director/
├── SKILL.md          # рантайм — грузится каждую сессию
├── profile.md        # твои ответы
├── journal.md        # журнал косяков и успехов (ведёт сам)
├── memory/           # только tier lite
└── references/        # core/00–06 + skills.md + models.md
```

Мастер предложит автозагрузку (SessionStart-хук для Claude Code; для остальных сред файл правил читается сам).

## Переконфигурация

```
/director
```

Профиль есть → спросит, что менять. `journal.md`, `memory/` и данные в LightRAG/PostgreSQL не трогаются.

## Ничего не сломает

Перед любыми изменениями визард делает **снимок** (`~/.director-backup/<дата>/`): копии конфигов, инструкций твоего агента, дампы БД + скрипт отката `restore.sh`.

- Сначала показывает, что у тебя уже есть, и что предлагает подключить — **ничего не удаляя**.
- Существующий LightRAG / базу / MCP — подключает, не пересоздаёт.
- Если сборка не удалась — сам откатывает всё назад к снимку и говорит, что пошло не так.
- Откат вручную в любой момент: `bash ~/.director-backup/<дата>/restore.sh`

## Приватность

Фаза 1: промокод проверяется локально, ничего не отправляется. Секреты (ключи, токены, строки подключения) в файлы скилла открытым текстом не пишутся — только ссылки на твои локальные файлы.

## Требования

- один из поддерживаемых агентов (см. «Среды»)
- git
- Docker — для памяти (LightRAG + PostgreSQL); либо доступ к уже развёрнутому LightRAG
- для делегирования на свой endpoint — рабочий OpenAI-совместимый API
