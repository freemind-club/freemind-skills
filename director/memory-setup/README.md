# Память директора

Директор **обязан** помнить между сессиями (`core/02-memory.md`). Что ставит визард:

| Бэкенд | Как | Зависимости |
|--------|-----|-------------|
| `native` | Штатная память среды (Hermes, Cursor). Директор пишет решения/факты в неё по правилам среды | нет |
| `files` | `MEMORY.md` + `journal.md` в каталоге директора | нет |

**Всё. Docker, PostgreSQL, LightRAG, MCP визард не ставит** — с версии 1.3.0 граф-память вынесена из пакета.

---

## Почему `files` — это ещё не всё

`files` работает, но recall = «прочитать индекс, открыть файлы по теме». Нет семантического поиска, нет связей между фактами, цифры (клиенты/метрики) в тексте, не запрашиваются. На большом объёме директор **чаще переспрашивает и тратит больше токенов** на повторный разбор того, что уже знал.

Снимает это **граф-память** (LightRAG + опционально PostgreSQL): семантический поиск по решениям + SQL по числам. Но она требует Docker, сервер и сопровождение — поэтому не в коробке.

## Как поднять граф-память (отдельно, решает пользователь)

Готовый установщик уже есть — модуль `mozg` в `freemind-setup` (LightRAG + PostgreSQL-brain, пишет `~/lightrag/credentials.txt`):

```bash
curl -fsSL https://raw.githubusercontent.com/freemind-club/freemind-setup/main/install.sh | bash -s mozg
```

Порядок:
1. Запусти директора на `native`/`files`, поработай.
2. Упрёшься в потолок (десятки проектов, нужны связи между фактами, нужна аналитика в числах) — сам решаешь, ставить ли граф-память командой выше. Помощь и контекст — клуб FreeMind: {{CLUB_LINK}}
3. Поднял → в `profile.md` директора смени `MEMORY_BACKEND` на `lightrag` / `lightrag_postgres`, добавь MCP **рядом** с существующими (конфиг не перезаписывать), перенеси накопленные заметки.

Директор ставить `mozg` сам не должен — это отдельная инфраструктура с Docker и сервером, осознанное решение пользователя.

> 🔴 Принцип 7 действует при любом бэкенде: мед./клиентские данные, секреты, чужая переписка не пишутся никуда без явного разрешения.
