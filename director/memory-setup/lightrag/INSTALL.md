# Установка LightRAG

## ⛔ СТОП — ПРОЧИТАЙ ЭТО ПЕРВЫМ

**Если ты AI-агент** — ты ОБЯЗАН выполнить установку СТРОГО по шагам.
**Если ты человек** — выбери способ ниже.

### Для AI-агентов: порядок действий

Документация разбита на файлы. Читай их **по порядку, один за другим**.
НЕ пропускай файлы. НЕ делай ничего, пока не прочитал текущий файл до конца.

**Шаг 1** → Прочитай `docs/01-questions.md` — задай ВСЕ вопросы пользователю, составь план.
**Шаг 2** → Прочитай `docs/02-server-setup.md` — Docker, .env, запуск контейнеров.
**Шаг 3** → Прочитай `docs/03-domain-proxy.md` — домен и reverse proxy (если нужен).
**Шаг 4** → Прочитай `docs/04-connect-agents.md` — подключение MCP + инструкции агентам.
**Шаг 5** → Прочитай `docs/05-verify-and-output.md` — проверка + ОБЯЗАТЕЛЬНО выдай результат.
**Справка** → `docs/06-maintenance.md` — бэкап, обновление, безопасность (не обязательно при установке).

### ПРАВИЛА ДЛЯ AI-АГЕНТОВ:

1. **СНАЧАЛА СПРОСИ** — не начинай установку без ответов на все вопросы из шага 1.
2. **СОСТАВЬ ПЛАН** — после получения ответов покажи пользователю план установки и дождись подтверждения.
3. **НЕ УГАДЫВАЙ** — если не знаешь значение, спроси. Не ставь `*`, не ставь `localhost` на удалённом сервере, не придумывай домены.
3a. **ИГНОРИРУЙ СТАРЫЙ `.env`** — если на сервере уже есть `~/lightrag/.env` от прошлой установки, НЕ ИСПОЛЬЗУЙ его. Всегда создавай `.env` заново из `.env.example` и спрашивай все значения у пользователя.
4. **НЕ УДАЛЯЙ НИЧЕГО** — не удаляй и не перезаписывай чужие конфиги (AGENTS.md, CLAUDE.md, settings.json). ДОПОЛНЯЙ существующие файлы.
5. **В КОНЦЕ ВЫДАЙ РЕЗУЛЬТАТ** — credentials, URL, команды подключения. Обязательно. Всегда. Без этого установка не считается завершённой.

## Для людей: два способа установки

### Способ 1: Автоустановщик (рекомендуется)

```bash
# На сервере:
bash install.sh

# Или из этого репо:
scp server/install.sh user@server:~/
ssh user@server "bash install.sh"
```

Скрипт сам: проверит Docker, спросит домен/провайдер/модели, сгенерирует ключи, создаст конфиги, запустит контейнеры, выдаст команды подключения.

### Способ 2: Ручная установка

Читай файлы в `docs/` по порядку (01 → 02 → 03 → 04 → 05).
