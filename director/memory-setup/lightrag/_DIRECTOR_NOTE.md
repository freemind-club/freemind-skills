# Заметка: этот скилл внутри `director`

Используется мастером `director` **только для LightRAG-половины памяти** (Docker + LightRAG + PostgreSQL, подключение MCP).

**Игнорировать** при работе из директора:
- шаги про OpenClaw / Paperclip / `AGENTS.md` / `USER.md` (`docs/04`) — у директора своя инструкция памяти в `core/02-memory.md`;
- блок памяти из `agents/CLAUDE.md` — **не** добавлять в `~/.claude/CLAUDE.md`, достаточно подключить MCP.

**Важно:** если LightRAG уже развёрнут и в нём есть данные — правило `docs/01` «ИГНОРИРУЙ старый .env» **не применять**: подключиться к существующему инстансу, `.env` не пересоздавать, модель эмбеддингов не менять (см. `../README.md` Шаг 1).
