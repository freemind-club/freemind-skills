# Адаптер: Hermes

Hermes — постоянный агент (Telegram-гейтвей + Kanban + cron), не сессии. Факты — из локальной установки (`/usr/local/lib/hermes-agent`, каталог профиля `${HERMES_HOME:-~/.hermes}`). Все пути ниже — относительно `${HERMES_HOME:-~/.hermes}`: если у {{USER_NAME}} профиль не в дефолтном каталоге, брать его (`hermes` уважает переменную `HERMES_HOME`).

## Память — `native`, через штатный tool `memory`

У Hermes **уже есть** штатная постоянная память (`memories/MEMORY.md` — заметки агента, `USER.md` — профиль пользователя, + история сессий).

В Hermes v0.21.0 долговременная память меняется **только через native tool `memory`**: `target='memory'` — решения/факты/уроки, `target='user'` — кто такой пользователь; действия `add` / `replace` / `remove`, несколько правок за раз — массив `operations` (атомарно, лимит объёма проверяется на итог). Инструмент держит лимит, атомарную запись и снимок памяти в системный промпт.

🔴 **НЕ редактировать `memories/MEMORY.md` / `USER.md` напрямую.** Прямая правка расходится со снимком инструмента (срабатывает защита от рассинхронизации) и может сломать память. Только `memory(...)`.

Стартовый recall — штатным механизмом Hermes (память уже в системном промпте; поиск по прошлым сессиям — `session_search`). Ничего ставить не нужно: **`MEMORY_BACKEND` для Hermes всегда `native`.**

Граф-память (LightRAG) в пакет не входит (с 1.3.0). Нужна — ставится отдельным проектом, потом `MEMORY_BACKEND` вручную меняется на `lightrag*` и MCP добавляется рядом. См. [../memory-setup/README.md](../memory-setup/README.md).

🔴 Данные пациентов/клиентов, секреты, чужая переписка (принцип 7) — не пишутся в штатную память без явного разрешения на конкретную запись.

## Механика

| Аспект | Как |
|--------|-----|
| Инструкции | блок между маркерами **в конец** `SOUL.md`; существующий текст персоны не трогать |
| Профиль | tool `memory(target='user', ...)` — **дополнить**, не переписывать. Прямую правку `USER.md` не делать |
| Доктрина | каталог `director-doctrine/` = копии `core/00–04` + `models.md` + `skills.md`. **Сначала искать существующую доктрину рекурсивно** (`grep -rl` по frontmatter `name: director-doctrine` в `${HERMES_HOME:-~/.hermes}/skills/`). Нашёл одну — в т.ч. на нестандартном пути (`…/skills/autonomous-ai-agents/director-doctrine/`) — **не перезаписывать: показать diff, спросить, дописать между стабильными маркерами**. Нашёл несколько — показать пути, спросить какую. Не нашёл — создать рядом с тем `SOUL.md`, который реально используется в этом профиле |
| Оркестратор | `hermes config get model.default` |
| Протокол сессии (core/05) | **не применяется** — вместо него протокол задачи (в блоке ниже) |

## MCP

Директор на `native` памяти MCP-серверов **не требует** — визард ничего не подключает.

Если {{USER_NAME}} отдельно поднял граф-память и хочет её подключить: команды `hermes mcp add` сверять с **фактическим** `hermes mcp add --help` установленной версии (флаги и порядок опций между версиями менялись), пакеты — с закреплённой версией (`@g99/lightrag-mcp-server@…`, `@modelcontextprotocol/server-postgres@…`), «Enable all tools?» — **не отвечать `y` вслепую**, выбрать `select`. Это вне сборки директора.

### Протокол задачи (на каждое обращение / карточку Kanban)
1. Прочитать карточку/сообщение целиком
2. Поднять контекст по теме — штатная память Hermes (уже в системном промпте; прошлые сессии — `session_search`). «🔍 Смотрю…» если >3 сек
3. Трогает реальных людей / прод ({{PROD_DEFINITION}})? → ОК {{USER_NAME}}, не раньше
4. Затратная задача (много ходов) → «⚠️ лучше с компьютера», ждать
5. Делать, делегируя: {{CHEAP_STACK}}
6. Проверить лично — curl/логи, не «✅»
7. Записать выводы (решения / паттерны / уроки, не пересказ) через tool `memory` (`target='memory'`; профиль — `target='user'`). **НЕ** править `MEMORY.md`/`USER.md` напрямую. **Принцип 7:** чувствительное — не писать
8. **Git — не обязательно, это два раздельных решения:**
   - **(a) локальный commit** (наружу не уходит): только если задача в репозитории И {{USER_NAME}} просил зафиксировать → `git add` конкретных файлов (не `-A`) → прогон на секреты → `git commit`. Дальше можно остановиться — коммит остаётся локальным.

9. Отчёт в карточку: записал в память / сделано / проверено / (без git · коммит локальный · запушено) / осталось. Не завершается → сказать {{USER_NAME}}, не зависать
