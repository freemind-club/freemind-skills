# Модели — роутер

Ортогонально среде ([../adapters/00_ROUTER.md](../adapters/00_ROUTER.md)). Задаёт: какая модель — **оркестратор** (сам директор, `SELF_MODEL`), какие — **исполнители** для дешёвой пачки (`CHEAP_STACK`, по порядку, первый доступный побеждает).

## Файлы

| Файл | Что |
|------|-----|
| [anthropic.md](anthropic.md) | Claude напрямую / подписка — оркестратор по умолчанию |

## Правило цепочки

```text
детерминированное (парсинг, счёт, переименование) → скрипт, без модели
фильтр / классификация / да-нет / короткий ответ  → ollama → groq
рерайт / перевод / черновик / код по образцу      → CHEAP_STACK по порядку
код > 5 строк по ТЗ                                → codex / deepseek-chat / fireworks
архитектура / оркестрация / решение / общение      → SELF_MODEL
```

## Что мастер заполняет

- `SELF_MODEL` — из Блока 3 в7 / Т2
- `CHEAP_STACK` — из Блока 3 в8: упорядоченный список (напр. `1) субагенты 2) OmniRoute kiro 3) Groq llama-3.3-70b 4) Ollama qwen2.5`)
- `models.md` в рантайме = склейка **только** выбранных файлов, не все 5

## Секреты

Ключи — в `~/.director/models.env` пользователя. Шаблон формата → [../templates/models.env.template](../templates/models.env.template). В скилле и профиле — только имена переменных.

## Честно про экономику

- **На подписке (Claude Code / ChatGPT Plus):** делегирование экономит реальные лимиты и деньги — оркестратор дорогой, пачку гони на бесплатные.
- **На pay-per-token API:** экономия меньше (сам оркестратор платный за токен). Здесь ценность делегирования — скорость, параллелизм и чистый контекст оркестратора. Дисциплина всё равно та же.
