# Ollama (локальные модели)

**Роль:** самое дешёвое звено — фильтрация, классификация, да/нет, короткие ответы. Ноль расходов, работает офлайн.

| | |
|--|--|
| base_url | `http://localhost:11434/v1` (в Docker — `http://host.docker.internal:11434/v1`) |
| Ключ | не нужен (`ollama` как заглушка) |
| API-формат | OpenAI Chat Completions |
| Модели | `qwen2.5:7b` (универсал), `qwen2.5:3b` (быстро), `llama3.2:3b`, `nomic-embed-text` (эмбеддинги) |

## Когда

- Классификация: «это спам / не спам», «тема A / B / C»
- Да/нет решения в пайплайне
- Простая нормализация текста
- Всё, что делается за один короткий вызов и не требует качества топ-моделей

## Когда НЕ

- Длинные тексты, рерайт с тонкостью, код → Groq/Fireworks
- Рассуждение, архитектура → `SELF_MODEL`

## Вызов

```bash
curl http://localhost:11434/v1/chat/completions -H 'Content-Type: application/json' \
  -d '{"model":"qwen2.5:7b","messages":[{"role":"user","content":"Ответь одним словом: спам или нет? ..."}]}'
```

## Особенности

- Модель надо предварительно скачать: `ollama pull qwen2.5:7b`.
- На слабой машине держать 3b; 7b требует ~6 ГБ RAM.
