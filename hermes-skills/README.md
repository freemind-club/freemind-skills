# Скиллы для Hermes Agent

Готовые скиллы-«сотрудники» для [Hermes Agent](https://github.com/NousResearch/hermes-agent). Один скилл = одна папка с `SKILL.md`.

| Скилл | Что делает |
|---|---|
| [komanda-dispetcher](komanda-dispetcher/SKILL.md) | Диспетчер входящих: сортирует сообщения клиентов (тип, срочность, «горячий» клиент, попытка взлома) с уверенностью. Работает через Laya / Jev (MCP) или на твоей модели |

## Как поставить

Проще всего — попросить своего Гермеса в чате:

> Скачай скилл https://raw.githubusercontent.com/freemind-club/freemind-skills/main/hermes-skills/komanda-dispetcher/SKILL.md и установи его сотруднику (профилю) dispetcher в папку skills/neurosprint/komanda-dispetcher/.

Вручную: положить папку `komanda-dispetcher/` в `~/.hermes/profiles/<профиль>/skills/neurosprint/`.
