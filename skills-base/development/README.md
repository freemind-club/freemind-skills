# Разработка

Скиллы для кода, агентов и браузерной автоматизации.

| Скилл | Описание | Хештеги |
|-------|----------|---------|
| [coding-agent](coding-agent/) | Написать, отладить или объяснить код: Python, JS, SQL, bash | `#coding` `#dev` |
| [agent-team-orchestration](agent-team-orchestration/) | Разбить большую задачу на агентов и скоординировать их работу | `#agents` `#orchestration` |
| [agent-browser](agent-browser/) | Автоматизация браузера: парсинг, заполнение форм, тестирование | `#browser` `#automation` |
| [playwright-cli](playwright-cli/) | Браузерная автоматизация через Playwright | `#browser` `#testing` |
| [github](github/) | GitHub: PR, issues, CI/CD, code review | `#github` `#git` `#devops` |
| [code-god](code-god/) | Экспертный разбор кода: баги, безопасность, улучшения | `#codereview` `#security` |
