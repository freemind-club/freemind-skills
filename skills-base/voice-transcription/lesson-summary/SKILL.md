## Установка (один раз)

```bash
pip install -r ~/.claude/skills/lesson-summary/scripts/requirements.txt
# нужны также ffmpeg и (для YouTube) yt-dlp: brew install ffmpeg yt-dlp  /  apt install ffmpeg && pip install yt-dlp
```

Ключи — в переменных окружения или в файле `.env` (в текущей папке или `~/.env`):
- `GROQ_API_KEY` — **обязателен**, бесплатный: console.groq.com
- `DEEPGRAM_API_KEY` — необязателен (точнее расшифровка, есть бесплатный лимит)
- `CF_AI_TOKEN` + `CF_ACCOUNT_ID` — необязательны (запасной Whisper в Cloudflare Workers AI)

## Одна команда

```bash
python3 ~/.claude/skills/lesson-summary/scripts/process_lesson.py "<файл или ссылка>"
```

Принимает: видео (mp4, mov, avi), аудио (mp3, wav, ogg, m4a), ссылку на YouTube.
Внутри: ffmpeg → расшифровка (Deepgram или Groq Whisper) → Groq LLM (саммари, тайм-коды, ключевые мысли) → HTML + подпись.
Запись на час обрабатывается примерно за минуту. Есть кэш по источнику: повторный прогон мгновенный.

## Что получается

```
~/.claude/skills/lesson-summary/scripts/processed/<Название>_<ГГГГ-ММ-ДД>.html         — конспект
~/.claude/skills/lesson-summary/scripts/processed/<Название>_<ГГГГ-ММ-ДД>_caption.txt  — подпись под видео
```

Разделы HTML: «О чём урок», «Тайм-коды», «Ключевые мысли», «Полная транскрипция». После прогона скопируй оба файла в папку своего урока или проекта.

## На что смотреть

- **Подпись длиннее 1024 символов** — скрипт предупредит. Это лимит Telegram на подпись к видео: сжать тайм-коды.
- **Имена и термины** распознаются с ошибками («рилсы» → «рюсы»). Поправить в конспекте перед выдачей.
- **Быстрая речь с числами** — цифры могут поехать. Спорные числа сверить по записи или описать словами.
- **Что прозвучало сверх плана** (живые сбои, находки, вопросы участников) — выписать отдельным списком.
- Исходное видео не удалять и не переносить без слова владельца.
- Ключи не печатать в чат и не класть в git.
