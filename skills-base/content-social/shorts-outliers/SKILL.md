📌 **Напоминания**
- Нужно: ниша и аудитория клиента, его реальные кейсы с цифрами (без них темы будут общими), `yt-dlp`, ключи бесплатных моделей для разбора (необязательно).
- Цифры просмотров только реальные, из YouTube. Выдуманные детали кейсов вычищаем проверкой фактов.
- Воруем механику, не содержание: чужие ролики не перезаливаем.
- На выходе: таблица выбросов, механики, алгоритм записи и 10 тем. Займёт 15–25 минут.


Метод профиля Гермеса `reels` (скилл `neurosprint-reels`), автоматизированный для YouTube: **× = просмотры шортса ÷ медиана последних 15 шортсов автора** (2 самых свежих пропускаем, они ещё набирают). До 2× обычный, 3–5× интересно, **5× и выше выброс**. Медиана, а не среднее: один вирусный ролик среднее ломает.

Почему YouTube, а не Instagram: Instagram не отдаёт просмотры без входа, YouTube отдаёт через `yt-dlp` без ключей и бесплатно. Механика шортсов и рилс одна.

Скрипты: `~/.claude/skills/shorts-outliers/scripts/` (исходник: `05_workshop/скиллы/shorts-outliers/`). Нужен `yt-dlp`. Разбор (шаг 4) делает внешняя бесплатная модель через свой скрипт делегирования, если он есть (у FreeMind: `05_workshop/инструменты/utils/delegate.py`). **Нет скрипта: разбор делает сам агент** по тому же `prompts/analysis.md`, проверка фактов (шаг 5) обязательна в обоих случаях.

## Шаги

`RUN` = папка прогона в проекте клиента, например `04_freemind/05_Маркетинг/ютуб_выбросы/ГГГГ-ММ-ДД/`. Всё по проекту храним в проекте.

### 1. Запросы → каналы
Составь `RUN/queries.txt`: 12–20 запросов «тема + shorts» по нише клиента И по соседним нишам его аудитории (для Олега: бизнес, продажи, нейросети + мягкая ниша: психологи, коучи, тарологи, мастера).
```bash
python3 -I scripts/discover.py --dir RUN --queries RUN/queries.txt
```
→ `RUN/channels_candidates.txt` (имя|url|частота). Отбери 25–40 подходящих в `RUN/channels.txt` (формат `Имя|url`). Выкинь новостные, юмор, нерелевантные. Добавь известных авторов ниши и 3–5 иностранных для формата (`Имя|https://www.youtube.com/@handle`).

### 2. Медианы и выбросы
```bash
python3 -I scripts/outliers.py --dir RUN            # --min-x 5 --limit 40 --tab shorts
```
→ `RUN/outliers.json`, `RUN/outliers_table.md`. Каналы с «мало шортсов» живут в длинных видео: можно прогнать `--tab videos`.

### 3. Тексты выбросов
```bash
python3 -I scripts/texts.py --dir RUN --top 35
```
→ `RUN/outliers_texts.md` (автосубтитры ru → uk → en + название, описание, длительность). Видео не качается, .vtt удаляются.

### 4. Разбор внешней моделью
Заполни `prompts/analysis.md`: `{{CLIENT}}` (кто, ниша, аудитория, голос, призыв) и `{{FACTS}}` (ТОЛЬКО реальные кейсы и цифры из карточек клиента; для Олега: `04_freemind/01_Управление/ментор/02_компетенции/05_кейсы_и_отзывы.md`). Сохрани как `RUN/task.md`.
```bash
# если есть скрипт делегирования (FreeMind):
python3 -I 05_workshop/инструменты/utils/delegate.py --task RUN/task.md --file RUN/outliers_texts.md --out RUN/analysis_raw.md --mode pro --timeout 600
# если нет: агент сам читает RUN/task.md + RUN/outliers_texts.md и пишет RUN/analysis_raw.md
```

### 5. Проверка фактов (обязательно: модели выдумывают детали кейсов)
```bash
python3 -I scripts/factcheck.py --task RUN/task.md --analysis RUN/analysis_raw.md
```
Каждую подозрительную строку правит Claude: выдуманные сценарии и цифры заменить реальными фактами или убрать. Также вычеркнуть хуки, противоречащие позиции клиента (для Олега: «замени людей ботом»). Сохранить как `RUN/analysis_checked.md` и прогнать factcheck ещё раз, пока не 0 (общие ориентиры помечать «общий ориентир»).

### 6. Итоговый документ
`RUN/АЛГОРИТМ_шортсы.md`: шапка (метод, сколько каналов и выбросов, что проверено, ограничения) → `outliers_table.md` → 3–5 строк «главное по цифрам» → `analysis_checked.md` (таблица выбросов, механики, алгоритм записи, 10 тем, чего не делать).

В чат: путь к файлу, топ-5 выбросов с ×, 3 главные механики, честно что поправлено и что не проверено. Полный текст в чат не вываливать.

## Правила
- Цифры просмотров только из `yt-dlp`, никаких «примерно». Нет данных = «нет данных».
- Воруем механику, не содержание: не предлагать перезаливать чужие ролики.
- Названия YouTube отдаёт в автопереводе: предупредить.
- Механики по субтитрам = предположение без просмотра видео: советовать открыть 2–3 топовых.
- Факты клиента наружу не публиковать без его ОК.
